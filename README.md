# Weekly Tree (Cron Job)

Weekly Tree is a tool that allows users to receive weekly email updates from their choice of Linktree pages, all in one email.
- Your email along with subscribed Linktree pages are stored in a MongoDB collection
- This tool works by web scraping all of the events from each Linktree you supply, formatting them in an easily digestible manner, and emailing you the summary each week with direct links to the original postings
- Emails are sent once a week using this GitHub Action cron job
